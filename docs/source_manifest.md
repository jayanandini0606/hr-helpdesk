# AI-Powered HR Helpdesk — Source Manifest & Synthetic Provenance

## 1. Generation Parameters & Seed Specification

The dataset is generated deterministically using a fixed pseudorandom seed. Running the generator with the identical seed produces identical rows, IDs, relationships, and checksums.

| Parameter | Configuration Value | Description |
|---|---|---|
| **Random Seed** | `20261022` | Fixed seed for Python's `random.Random(20261022)` |
| **Generator Command** | `python src/generate_data.py --scale full` | Unified, parameterized CLI generator |
| **Starter Scale Command** | `python src/generate_data.py --scale starter` | Minimal baseline generation (25 tickets) |
| **Custom Scale Command** | `python src/generate_data.py --tickets 1000` | Custom parameterized volume scaling |
| **Timestamp Range** | `2026-04-01T09:00:00Z` to `2026-10-28T11:00:00Z` | Historical span across ~7 months |
| **Timezone** | UTC | All dates and timestamps are stored in UTC ISO 8601 |

## 3. Deliberately Labelled Anomaly Inventory (`evaluation/ground_truth.*`)

In accordance with Step 5 and Step 7, four deliberate negative scenarios were injected into the dataset and cataloged in a separate `ground_truth.json` / `ground_truth.csv` file without corrupting operational features:

| Ticket ID | Anomaly Label (`issue_type`) | Injected Anomaly Behavior | Expected QA / Evaluator Finding |
|---|---|---|---|
| `TKT-2026-000101` | `obsolete_policy_citation` | Assistant answer cites Retired Policy Version 1 (`VER-POL-HR-2026-001-01`) instead of current published Version 2. | Flagged as policy version boundary failure. |
| `TKT-2026-000102` | `sensitive_misrouted` | Confidential harassment complaint was routed to `HR-General` rather than `HR-Confidential`. | Flagged as confidential containment failure. |
| `TKT-2026-000103` | `sla_calendar_anomaly` | SLA resolution deadline calculated ignoring standard business working hours (using continuous 24/7 calendar). | Flagged as working calendar calculation bug. |
| `TKT-2026-000104` | `unsupported_policy_hallucination` | An inquiry regarding a 6-month mountaineering sabbatical was answered as an approved fact without policy backing. | Flagged as unsupported policy hallucination. |

## 5. Public Data Guidance & Lawful Use Statement

1. **100% Synthetic Data:** All employee names, employee IDs, email addresses, manager hierarchies, policy titles, and ticket conversations are synthetically generated by algorithmic procedures using random seed `20261022`.
2. **Zero Real Confidential Information:** No real human beings, confidential personal identifiable information (PII), protected health information (PHI), or actual corporate trade secrets were collected, scraped, or used.
3. **Lawful Schema Provenance:** Relational schemas and ITSM/HR service-delivery attributes are inspired by open enterprise frameworks (ITIL v4 Service Desk principles, standard public human-resources taxonomies) and designed from first principles for this code challenge.
4. **No External Network Dependencies:** The application and generation pipeline run 100% locally on standard Python and SQLite without calling paid, external, or unauthorized remote APIs.
